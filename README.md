# Traza · Fumigaciones

Sitio estático en HTML, CSS y JavaScript. Abrí `index.html` para una vista local.

## Contacto comercial

En `js/main.js`, completá `SITE.whatsapp` con el número comercial en formato internacional, sólo dígitos (ejemplo: `54911...`). El asistente pide nombre o empresa y una descripción libre del problema; luego prepara un mensaje con ambas respuestas. El visitante confirma el envío dentro de WhatsApp.

Mientras el número esté vacío, el botón abre WhatsApp con el mensaje preparado para elegir un chat. No existe un destinatario comercial preseleccionado.

Completá `SITE.instagram` con el enlace oficial cuando exista. Hasta entonces el botón no se muestra. El botón de Google Maps abre una búsqueda general de CABA; el mapa embebido muestra CABA y GBA como referencia visual. Confirmá cada localidad antes de prometer cobertura.

Las imágenes son ilustrativas. El catálogo enumera las cuatro plagas documentadas en el sitio; las demás consultas se atienden a través de la opción “Otra plaga”.
